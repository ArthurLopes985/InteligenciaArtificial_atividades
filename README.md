# InteligenciaArtificial_atividades

Repositório dedicado a matéria de Inteligência Artificial, do 6° semestre do curso de Engenharia de Software, na Universidade de Mogi das Cruzes.
Atividades utilizando a linguagem Python, em notebooks do Google Colab.

Lista de Atividades e explicações:
1. Exercícios_Python: Atividade introdutória a matéria e a linguagem, treinando desde coisas mais simples como hello world, somas, calculadora básica, passando por listas, manipulação de strings até verificação de CPF, sequência de fibonacci, números primos, criação de jogos como adivinhação, forca, jogo da velha. Para maiores explicações, o código está inteiramente comentado.
2. Atividades_de_Data_Science:_NumPy,_SciPy,_Pandas_e_Matplotlib:  Ativdade introdutória as principais bibliotecas para Python, 20 exercicios de Numpy, 20 de Scipy, 20 de Pandas e 20 de Matplotlib, totalizando 80 exercícios, que solicitam contas matematicas, das mais simples como quadrado até mais complicadas como Fourier, criação de Dataframes no Pandas e de gráficos no Matplotlib. Para maiores explicações, o código sempre vem acompanhado de um bloco de texto, que explica sua lógica.
3. Atividade de Aprendizado Supervisionado de Máquina: A partir de um código pronto de aprendizado usando categorização de flores a partir do linear, foi feito testes desses mesmos dados em não linear e polinomial.
4. Atividade de SVM com Dataset Iris: Parecido com a atividade anterior, mas realizado com arquivo .csv, criando dataframe no Pandas, e depois classificando flores pela suas caracteristicas.
5. Atividade de classificação com SVM: Usando um dataset de dados de câncer disponível no Kaggle, classificando câncer entre maligno e benigno de acordo com umas características, fazendo aprendizado de máquina.
6. Eleicão de 1936: A partir das pesquisas para presidente dos EUA de 1936 da Literary Diggest, foi tentado corrigir o resultado, que foi altamente errado, levando a falencia da revista, foi usado regressão linear para calcular as margens de erro de 1932(pesquisa anterior) e aplicada essa margem ao resultado de 36.
7. SVM Soccer: Atividade no Kaggle de repositório a livre escolha, escolhemos de futebol. A partir disso foi passado inúmeras classificações de jogadores de futebol, e a meta do aprendizado de máquina era predizer o overall do jogador. O modelo alcançou um resultado razoável, com média de 75% de acurácia.
8. Exercicio Arvore de Decisão, Floresta Aleatória, Boosting: Atividade de Machine Learning que utiliza 5 datasets de classificação (SVM) e 1 de regressão linear para testar e comparar o desempenho de três algoritmos: Árvore de Decisão, Floresta Aleatória (Random Forest) e Gradient Boosting.
